# Contributor Covenant Code of Conduct

This project follows the Contributor Covenant v2.1 to foster an open and welcoming community.

Our expectations

- Be respectful and considerate in all interactions.
- Assume positive intent.
- Be open to feedback and changes.

Reporting

If you experience or witness unacceptable behavior, please open an issue or contact the maintainers so we can address it.

For the full text of the Contributor Covenant, see: https://www.contributor-covenant.org
